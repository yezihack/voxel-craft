## 新增 `dev.bat`（Windows 双击启动）

- 流程：`cd /d "%~dp0"` → `where node` 检查 → `node_modules\vite\package.json` 不存在则
  `npm install`（失败自动降级 `--ignore-scripts`，正是为了绕开上面那个沙箱 EBUSY）→ `npm run dev -- --open`
- 参数：`dev.bat nobrowser` 跳过自动开浏览器
- **编码约定（关键）**：文件存 **UTF-8 无 BOM + 全 CRLF**，首行 `@echo off`、次行 `chcp 65001 >nul`。
  实测 Windows 10 19044 下中文提示无乱码、`goto :fail` 标签跳转正常。
  Write/Edit 工具会写成 LF，**改完必须用 `sed -i 's/\r*$/\r/' dev.bat` 转回 CRLF**。
- 已实测：脚本启动的服务器 HTTP 200，`nobrowser` 分支提示文案正确切换。

**代码侦察得到的硬约束（后续实现必须遵守）**：
- 贴图集 256 格**已用 147**，余 109 → 汉字不可能一字一格做方块贴图，只能 DOM 覆盖层；
  A–Z 26 格可行（占后 173/256）
- `textures.js` 无 `fillText`，3D 世界内零文字渲染能力；但离屏 canvas 画贴图可以用 fillText
- `nametags.js` 已有 viewProj→NDC→CSS 变量 的 DOM 标签投影通道，世界内题干**直接复用**
- `DIM_N=8` 与 `PORTAL_BLOCK`/`CORE_ITEM`/`dimSpawn` 多表绑定 → 新增维度代价高，故学习区走主世界结构
- 结构系统 7 种（`collectStruct` + 形状缓存），加第 8 种「学堂」成本低；但需**重分 `structAt` hash 概率区间**
- 合成系统是 3×3 字符网格滑动匹配 → 拼写合成复用 `craftSlots`，但**不要塞进 `RECIPES`**（400 词会炸表）
- 项目**零持久化**（无 localStorage/IndexedDB/账号）、**零语音**（audio.js 只有振荡器）
- `config.js` 是叶模块有 TDZ 纪律 → 学习层是其**下游**，只能追加方块/物品 id，不许插队

**关键设计洞察**：拼音与英语共用同一套 A–Z 字块（26 格服务两个学科，且「拼单词」与
「看拼音写词语」收敛成同一交互）；汉字物品用**通用底板图标 + DOM 叠字**，不占贴图格。
