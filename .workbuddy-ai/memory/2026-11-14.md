## 创造模式免疫怪物攻击：统一「玩家是否可被攻击」判定

- 用户「让创造模式下的玩家不会受到怪物攻击」。确认口径：怪物完全无视玩家（不追 / 不挥 / 不射 / 不炸 / 不击退），怪仍游荡且仍打傀儡与 AI 玩家；验证走纯 Node AI 探针。
- 根因：`survival.js` 的 `hurt()` 早有 `mode !== MODE.SURVIVAL` 免伤，创造模式本来就不掉血；但攻击的其它副作用全部绕过 hurt —— `hostileTarget()` 只排除 `MODE.SPECTATOR`、`updateArrows()` 的 foe 命中判 `mode !== SPECTATOR`、`explodeMob()` 的玩家击退也只判 SPECTATOR。红探针实测创造模式被僵尸打飞 `vx=10.40 / vy=3.40`、进挥击冷却 `atkT=1.00`、foe 箭仍被吞、爆炸击退 `vx=-7.74`。
- 做法：`survival.js` 新增唯一判定 `playerAttackable() = mode === MODE.SURVIVAL && !player.dead`；`hurt()` 合并原先 `p.dead` 与 mode 两行；`mobs.js` 的 `hostileTarget` / `updateArrows` / `explodeMob` 三处共用它。`hostileTarget` 是杠杆点：骷髅放箭、苦力怕引信、boss 喷弹与爆破全挂在 `if (T)` 下，目标一断整体静默。保留爆炸破坏方块（世界行为）与 `bots.js` 里等价的 AI 玩家攻击判定。
- 验证：`.scratch/creative-immunity/probe.mjs` 32/32；三片红→绿（3 条失败 → 2 条失败 → 审查补强 7 条）；`npx vite build` 114 modules 通过。双轴审查：Standards 无成文标准违规；Spec 指出「凋灵不爆破」是空断言、bot / 傀儡实打 / 游荡 / 旁观 / 死亡玩家漏测，已全部补齐。
- **回归坑（重要）**：`.scratch/gap-fall/probe.mjs` 与 `.scratch/boss/probe.mjs` 从未显式设 mode，默认 `MODE.CREATIVE`，靠「怪追玩家」驱动 AI / 物理 / boss 召唤与爆破；本次改动让它们 20 条 / 2 条断言假阴性。各补一行 `setModeState(MODE.SURVIVAL)` 后恢复全过。这是测试前提被需求改变，不是产品回归。
- 其它回归：`bot-hurt` / `sunburn` / `mine-density` / `spell-craft` 纯 Node 全过；`bots` 的「空手死亡偶尔掉落火把」是历史随机偶发（连跑 3 次全过）；`potions` / `enchant` 在重起的干净 dev server（5190）+ 系统 Chrome 下也全过（药水零控制台报错、贴图 244 格；附魔 52 项）。
