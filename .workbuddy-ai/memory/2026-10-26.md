### 存档（新模块 `save.js`）
- 地形是纯函数 → **不入档**；只存「世界参数 + 8 维度覆盖层 + 玩家状态」。
- 读档顺序：种子/世界类型 → 清 colCache+structShapeCache → 重建 8 张 dimEdits →
  `setDim` → **重指 `setEdits`** → 时间 → 玩家 → 背包 → 盔甲 → 模式 → `initChunks`。
- 读档必须清场（mobs/bots/掉落物/carts/arrows）；`dead` 一律清掉；槽位与 inv 对账。
- 存储层：浏览器 localStorage / node 内存 Map（probe 能测全链路）；配额满返回 `{ok:false,reason:'quota'}`。
- meta 单独存（时间/维度/模式/改动格数）；自动存档 60 秒一次（只在 running 时）。
- 入口：F5 存 / F9 读（F5 必须 preventDefault）；开始/暂停面板显示摘要 + 删档按钮。
- 新世界 = 删档 + `location.reload()`（逐项重置引擎状态太容易漏）。
