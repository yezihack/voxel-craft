# 2026-10-27

## 移除左上角 HUD + 触屏可玩性改造

玩家反馈：左上角两块常驻文字卡（状态行 + 九行按键说明）挡视野；手机上基本不能玩。

### 删掉的
- `components/HudPanel.vue`、`components/HudCard.vue`、`data/helpKeys.js` 三个文件整块删除。
- `uiState` 去掉 `stat` / `flyTag`；`loop.js` 去掉 `syncHud` 调用与只为 HUD 统计的
  `drawn` / `tris`；`uiSync.js` 只留 `syncVitals` / `syncHurt`。
- `main.css` 的 `.card` / `.card b` / `.card kbd` / `.dim` 四条死样式一并删。
- 飞行开关（键盘 F / 触屏按钮）改播 toast，不再写 `ui.flyTag`。

保留：`Vitals`（心形/鸡腿/气泡）、准星、挖掘环、弓蓄力条、`Toast` —— 图形反馈与瞬时提示不占视野。

### 触屏手势重新分工（关键决定）
改造前画布叠了三个手势：按住挖 / 长按 380ms 放 / 拖动转视角。电容屏分不清
「手指停顿」与「长按」，想转头经常挖出坑。现在画布**只**保留滑动转视角：

- `input.js` 画布 `touchmove` → `addLook(dx * TOUCH_LOOK)`，`TOUCH_LOOK = 2.2`
- `pointerdown` 显式 `if (e.pointerType === 'touch') return`，否则同一次滑动被
  pointer 与 touch 两套监听各算一次，灵敏度翻倍
- 挖 / 放改成右下两个专用按钮，走 `uiActions.touchMine` / `touchPlace`

`touchPlace` 复用 `placeHeld` 之后，弓蓄力与盾牌格挡自动跟着生效（本来就是「按住右键」语义）。

### 触屏控件布局
左摇杆（118px，`env(safe-area-inset-*)`）· 右下 2×2 四颗 68px（跳/潜/挖/放，挖放主色）
· 右上 背包/模式/飞行/菜单。**砍掉了右摇杆转头**（拇指要先找圆心，不如「哪儿都能滑」）。

### 触屏没有键盘 → 补的入口
F5 存档 → 暂停面板「💾 保存进度」（`ui.started` 后才出现）；Esc 暂停 → 右上「菜单」
（`pauseGame`）；G 切模式 → 右上「模式」（`cycleMode`，与键盘 G 共用同一入口）。

### 移动端细节
- `canvas { touch-action: none }` 禁掉滚动 / 下拉刷新 / 双指缩放
- 快捷格在 `max-width: 560px` 缩到 36×44、隐藏名字与键位号，9 格才排得进竖屏
- 生命条 `@media (pointer: coarse)` 抬到 bottom 86px，不压快捷栏
- **渲染倍率触屏上限 1.5**（桌面 2.0）：手机 DPR 常为 3，按 2 倍是 2.2M 像素，
  中端机掉到 20 帧以下
- `StartVeil` 触屏下换成四行触屏说明，不再提「锁定鼠标」
