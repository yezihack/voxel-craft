## 修复：火把/铁轨透视

根因：mesher.js `buildChunk` 面剔除逻辑对每个方块检查 6 面邻居，
若邻居 `isOpaque` 则剔掉朝向它的面。generate.js 的 `isOpaque` 谓词
原先只排 `alpha` 和 `liquid`，没排 `shape`，导致火把/铁轨（带 cross/plate
shape）被误判为不透明 → 相邻实心方块朝向薄片那一面被剔掉 → 薄片背后空了
一片 → 透视。

修法：`isOpaque` 加 `!B.shape`，一行修复。
```js
export const isOpaque = (id) => {
  if (!(id > 0)) return false;
  const B = BLOCKS[id];
  return !!B && !B.alpha && !B.liquid && !B.shape;
};
```
