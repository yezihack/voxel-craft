## 踩坑

- **`wrangler login` 的 OAuth 只有 2 分钟有效期**。第一次在后台跑，
  用户点授权时进程已经超时退出（日志里是
  `Timed out waiting for authorization code`），只能重新发起。
  另外 `npx wrangler login | head -30` 会因管道缓冲看不到任何输出 ——
  后台跑这类交互命令要 `> file.log 2>&1` 再 `cat`。
- **`npx wrangler` 默认版本会 notarget 失败**，得显式 `npx wrangler@3`。
- **`wrangler pages deploy` 首次会交互询问是否新建项目**，
  先 `wrangler pages project create <name> --production-branch=main` 更稳。
- **playwright 的 ESM import 不吃 NODE_PATH**，要
  `createRequire(PW_ROOT + '/x.js')` 再 `req('playwright')`（沿用 shot.mjs 的做法）。
- **脚本里 `const URL = ...` 会遮蔽全局 `URL` 构造函数**，
  后面 `new URL('.', import.meta.url)` 直接 TypeError。命名成 `PAGE_URL`。
- **`git add -A` 把 wrangler 日志一起提交了**，`cf-whoami.log` 里带账号邮箱和
  Account ID。仓库刚建没人克隆，用 `reset --soft` + `--force-with-lease`
  重整历史抹掉，并把 `.scratch/**/*.log` 加进 .gitignore。

## 摇杆松手不停 + 超平坦保留建筑（17:30）

### 摇杆「一直往前走」的根因
`loop.js` 里 `if (stickVec.x || stickVec.y) { input.f = ... }` —— 手指一松、
向量归零，**整个分支被跳过**，上一帧的 `input.f = true` 没人清。
键盘没事是因为 `keyup` 会显式置 false，摇杆没有「抬起事件」，全靠每帧读向量。

- 换算抽到 **`src/game/stick.js`**：`stickInput.active` 记「方向键归摇杆管」，
  接管期内每帧都写（含归零那一帧），写完再退出接管 → 桌面 WASD 不被覆盖。
  `releaseStick()` 给「面板抢焦点 / 死亡 / 切维度」用。
  单独立文件是为了能在 node 里单测（loop.js 一进 node 就炸）。
- `TouchControls.vue`：`onStart` 加 `if (id !== null) return`（第二根手指不劫持）；
  `onEndEvt` 加兜底（identifier 对不上但页面上已无手指 → 无条件复位）。
- 顺带修首屏竞态：引擎异步拉起，开始面板第一帧就可点 →
  `engine.pickWorldType is not a function`。`engine.js` 先铺一层占位 noop
  （点了把提示语改成「引擎还在加载」），`initEngine` 再整体覆盖。

### 超平坦现在会生成建筑
`generate.js` 的 `flatWorld` 分支改成**先查 `structBlockAt`（所有 y）**，
查不到再走草/土/石/基岩。树/南瓜/胡萝卜/仙人掌/水仍然一律不生成
（它们在那三个函数里，这条分支压根不走）。
结构密度沿用经典规则，不特殊调稀：96 格一个结构格，58% 有建筑，
平原分支 62% 是村庄。实测 11×11 格有 80 处建筑。

## 第二轮：AI 玩家挨打不掉血 / 生物上限 / 挖放距离 / 手机闪退

### AI 玩家挨打不掉血 —— 真凶是「回血比伤害快」
链路本身没断（近战 / 箭矢 / 爆炸 / 凋灵爆破都通），问题是 bots.js 三路回血
（eat 5/s、home 2.5/s、定时 +1/3.5s）叠起来超过僵尸 3/s 的输出，血条看着就是不动。
- `damageBot` 里置 `b.regenBlockT = 6`，`botStep` 每帧递减；三路回血都加
  `b.regenBlockT <= 0` 门槛，且速率下调（home 2.5→1.2/s，eat 5→2.5/s，定时 3.5s→6s）。
- **教训**：以后加任何回血来源，必须过 `regenBlockT`，否则又会被「边打边满」掩盖。

### mobs → bots 的注入方式（绕开循环依赖 + TDZ）
bots.js 已 import mobs.js，反向 import 成环。用 `botHook = { list, damage }` 注入：
```js
export const botHook = { list: null, damage: null };
export function registerBots(list, damage) { ... }
```
- **TDZ 坑**：bots.js 顶层直接调 `registerBots` 会撞
  «Cannot access 'botHook' before initialization»（mobs.js 的 const 还没初始化）。
  改成幂等 `installBotHook()`，由 `boot()` 和 `spawnBot()` 触发。

### 攻击距离必须与挖放距离解耦
`REACH` 拉到 13 后，如果攻击也吃 13，就是隔空点杀。拆成
`REACH`（挖/放/上车/召唤/点燃）与 `REACH_ATTACK = 9`（打怪/打 bot/旁观射线）。

### 手机闪退三堵（桌面复现不出，只能按成因堵）
1. 触屏判定放宽：`ui.touch = touchy && (coarse || innerWidth <= 900)`
   —— 以前只看 `pointer: coarse`，某些安卓 WebView 报 fine。
2. `pointerlockerror` 在触屏下直接 return（手机永远拿不到锁，以前会抛异常）。
3. `webglcontextlost` → preventDefault + 存档 + 900ms 后 reload；
   `visibilitychange` 切后台 → 存档 + 暂停；`window.onerror` / `unhandledrejection`
   → 兜底显示 `FatalNotice`，把真实错误亮给用户而不是白屏。

### 测试踩坑
- 箭矢/僵尸近战用例必须在 y=60 高空或同时跑 `mobPhysics`，否则箭出生撞地形、
  僵尸永远停在 atkRange 外 → 假阴性。
- `spawnMob` 本身不查上限（挡板在 `updateMobSpawn` / `trySpawnEgg`），
  测上限要测「塞满后自然刷怪不再往上堆」。
- `hurt-shot.mjs` 抓错人两次：`bots[last]` 抓到游戏自己刷的；`spawnBot` 造的会被
  「跑远回收」带走。正解是搬运 `bots[0]` 并给它设 `home`。

## 第三轮：手机竖版控件被挡

### 现象与根因
竖屏生存模式下，10 颗心 + 10 个鸡腿横在屏幕中部，**正压着左摇杆和右下「挖 / 放」**；
窄屏（≤360 宽）底部 9 格物品栏宽 368px，**首尾两格被屏幕边缘裁掉**。
- `Vitals.vue` 触屏断点是 `bottom: 100px`，而摇杆与 2×2 动作区底边**也是 100px**
  → 三者同一条水平带。横屏按钮在两侧、中间有缝看不出来，竖屏中间只剩几十像素。
- 物品栏格子固定 36px，9 格 + 间隙 + 内边距 = 366px，360 屏溢出 6px、320 屏溢出 48px。

### 做法
- 生命值触屏改**左上角**（`.vitals.touch`）：`left:10px / top:52px`，图标 16→13px。
  `top` 取 52 不是 8 —— 360 宽时右上系统栏（210px 宽右对齐）伸到 x=138，
  而 10 颗心到 x=149，贴顶会撞，下移一行彻底分开。删掉 `(pointer: coarse)` 那条。
- `ItemSlot.vue` 加 ≤400px（32×40）与 ≤350px（28×36）两档，
  `HotBar.vue` 同步收 gap/padding。**不给容器设 max-width**：
  flex 不会自动缩子元素，设了只会让背景比内容窄。

### 验证
`.scratch/mobile/check.mjs` 量 bounding rect + 两两重叠：
320×568 / 360×740 / 390×844 竖屏生存、640×360 小横屏、844×390 横屏 —— **全部无重叠、无越界**。
`npx vite build` 100 modules，CSS 20.73 kB（+0.13）。

### 测试踩坑（重要）
- **`import('/src/engine.js')` 在 dev 下会拿到与组件不同的模块实例**（vite 的 HMR query 不同），
  读到的是 `NOT_READY_KEYS` 占位 noop，`engine.startGame.toString()` 里是「引擎还在加载」，
  看起来像「引擎没初始化 / 按钮点不动」。**判断按钮可用性只能靠 DOM 观察，别 import。**
- 等「地形就绪」要**连续 3 次采样一致**才算稳定。只等一次会在进度条抖动时假通过，
  接着点开始按钮正好撞上面板重渲染，看起来像按钮没反应。实测鼠标点坐标 → `veil hide` 正常。
- 竖屏生存模式刚开局背包是空的，物品栏 9 格全空是正常的，不是图标没渲染。
