
## 2026-10-29 存档导出 / 导入（防丢档）
- 存档只存在 localStorage，清浏览器数据 / iOS 7 天回收 / 隐私模式都会丢。
- save.js 新增 `exportSaveJson()`（无档退回内存快照）与 `importSaveJson(text)`
  （校验 JSON + 版本号 → 写回 SAVE_KEY → 重建 meta）；导入即替换浏览器存档。
- uiActions 新增 `exportSave()`（先 saveGame 再 Blob 下载）与
  `importSaveFile(file)`（读文件 → 导入 → loadNow 立即进世界，复用清场逻辑）。
- StartVeil（开始/暂停共用面板）加 ⬇导出 / ⬆导入 两枚 `.iobtn` +
  隐藏 file input；change 后清空 value，同一文件选第二次也能触发。
- 测试：`saveio/probe.mjs` 19 条 + `saveio/e2e.mjs` 9 条（真下载 + 真文件导入）
  全过；build 100 modules。
- 提交与部署见 git log。
