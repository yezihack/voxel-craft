## 12 种药水 + 生物/方块贴图重绘

### 药水系统（新模块 `src/game/potions.js`）
只依赖 `config.js`，不碰 DOM / GL / player / survival，避免成环。
反向边（`config.toolSpeedOn` 要急迫倍率）走注入：`setPotionHasteReader`，
在 potions.js **文件末尾**调用 —— 和 `setEnchantReader` 同一个套路，
代价也一样：potions.js 必须被求值一次，否则急迫**静默失效**。

12 种效果全部接进真机制，不做纯数字装饰：
- 即时型：治疗（+6 生命，走 `survival.heal`）
- 迅捷→`player.updatePhysics` 的 speed 乘算 / 跳跃→JUMP_V 乘算
- 力量→`mobs.js` 挥击 `attackDamage() + potionStrengthBonus()`
- 抗性→`survival.hurt()` 末段乘算（外部打击才吃，环境伤害 `{pierce:true}` 不吃）
- 再生 / 剧毒→`updateSurvival` 秒级累加器（剧毒走 `hurt(...,{pierce:true})`）
- 夜视→`loop.js` 的 `uAmbient` 抬到 0.86
- 水肺→溺水判定加 `!potionWaterBreath()` / 抗火→岩浆 tick 跳过
- 急迫→`config.toolSpeedOn` 乘算
- 缓慢→速度乘 0.60（与迅捷相乘 = 0.87）

### 三个刻意的设计决定
1. **同种药水不叠层**：重复喝取 `Math.max(剩余, dur)`，否则「连喝五瓶迅捷 = 5 倍速」。
2. **`potionRestore` 逐条校验**：键存在 / 非即时型 / 时长 `Math.min(t, dur)` ——
   存档是玩家能手改的文件，不校验就是给人送 999999 秒抗性。
   `applySave` 里**无条件**调用，老档没 `potions` 字段时全清。
3. **先 `applyPotion` 再 `invTake`**：反过来的话失败时药水凭空消失。

## 贴图：`potionIconTile` 的 P/Q 陷阱（重要）
第一版瓶子渲染出来只有**格子左上四分之一大**、右下三块空白。
根因：函数用 `P(x, y, col)` 逐像素画 0..15 的坐标，而 `P` 是 32×32 格内的
**单像素**。16×16 逻辑格必须走 `PQ()`（`IU = TP/16 = 2` 倍块）。
`PQ` 没有 alpha 参数，所以在函数内定义局部 `Q(x,y,col,a)` 复刻一遍带透明度的版本。
**以后写任何 16×16 逻辑格图标，一律 `PQ`/`Q`，不要用 `P`。**

瓶形最终版：逐行描述 `[y, x0, x1, 部位]`，宽度 4→2→4→6→8 逐级外扩再收口
（瓶塞 4 宽 / 细颈 2 宽 / 瓶肩过渡 / 瓶身 8 宽 / 圆底）。
两个关键视觉决定：
- **瓶身最外列不能用纯 `glassDk`**：会把整只瓶子洗成白色，液体色只剩中间一条。
  正确做法是先铺 `shade(c, -34)` 再叠 `glassDk` alpha 0.42 —— 既有玻璃壳高光边，
  主调仍是液体色。
- **空瓶不能用 0.3 透明内部**：叠在物品栏背景上几乎看不见轮廓，改淡蓝白实心
  `[202,220,232]` + 边 `[178,198,214]`。
- 白十字 4×3（`x=7,8 × y=9..11` + `x=6..9 × y=10`），原来 4×4 会占满整个瓶身。

## 贴图：`P()` 的颜色越界（第二个坑，同日发现）
`shade(c, -76)` 在深色基色上会算出**负数**，`rgb(-22,-26,-22)` 是**无效 CSS** ——
canvas 遇到无效值会**保留上一次的 fillStyle**，于是那一格画出的是上一个贴图的颜色。
症状：凋灵的脸（基色 `[28,24,28]`，原实现 `shade(c,-50)`）整块糊成黑，五官全看不见。
修法：在 `P()` 里加 `cl(v)` 把三个通道钳到 0..255。**任何 `P`/`PQ`/`PL` 的调用方
都不需要再自己防负数。**

顺带发现「亮基色上小幅度噪声等于没画」：
- 雪傀儡基色 240，原来 ±8 → 看着就是一块纯白。改成大颗粒 ±28 + 右下暗部 -20 +
  10 个灰杂质点 + 26 个亮晶。
- 铁傀儡基色 198，原来 ±14 看不出。改成面板 ±30 + **竖向拉丝**（每隔 3 列一条
  暗线，铁板压延痕）+ 板缝 -62 + 四团锈斑。金属感主要来自「成条的暗线」，
  不是随机噪声。
- 深基色不能靠 `shade(c,-50)` 压暗，直接用固定色（凋灵脸改 `[48,42,52]` 底 +
  发光紫瞳 `[176,84,208]`）。

## 实机截图（`.scratch/potions/shot.mjs`）
切模式必须走 **`uiActions.setMode(m, false)`**，不能用 `state.setModeState(m)` ——
后者只改引擎侧的 `mode` 变量，`ui.survival` 不更新，于是 Vitals 与 PotionHud
**都不出现**（截图里右上角空着）。而且 `setMode` 内部会 `player.fly = false`，
所以飞行要在它之后设。
快捷栏摆物品要**两条路都写**（`invSlots` + `HOTBAR`），不确定 `activeSlots()`
返回哪一个时这样最省事；数量仍统一记在 `inv`（Map）里。
