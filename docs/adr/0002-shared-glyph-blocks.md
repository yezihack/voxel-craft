# 拼音与英语共用一套 A–Z 字块

英语拼写与汉语拼音共用同一套 26 种「字块」，而不是各做一套。

26 格贴图同时服务两个学科，贴图预算从 52 格降到 26 格；更关键的是「拼单词」与
「看拼音写词语」收敛成了同一个交互，合成台那套 3×3 滑动匹配逻辑可以原样复用。

## Consequences

- 方块上无法表达声调，ā á ǎ à **一律交给 DOM 层显示**；字块只承载不带调的字母。
  拼写判定同样按不带调的字母序列匹配——声调不进答案，也不进判定。
- 字块是**方块**（可放置），汉字是**物品**（不可放置）——两者在 `BLOCKS` / `ITEMS`
  里分属不同 id 段，不要为了统一而混。
