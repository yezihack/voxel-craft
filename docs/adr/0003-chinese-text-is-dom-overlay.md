# 中文文本一律走 DOM 覆盖层，不烘进贴图集

所有中文文本（题干、诗句、选项、背包里的汉字）走 DOM 覆盖层渲染，不生成方块贴图。

贴图集只有 256 格、已用 147，汉字「一字一格」在 3–4 年级的词汇量（数百字）面前
完全不可行；而 `nametags.js` 的 viewProj → 屏幕坐标 → CSS 变量通道已经是现成能力，
中文挂进世界不需要新写投影。背包里的汉字物品用**通用底板图标 + DOM 叠字**。

## Consequences

- 文字不随 3D 透视变形，永远正对屏幕——这是取舍，不是缺陷，也不必去「修复」。
- 距离剔除、淡出、遮挡判断都要自己写，不能白嫖 3D 深度缓冲。
- 英文字母是**例外**：A–Z 是有限的 26 个，可以进贴图集（见 ADR-0002）。
