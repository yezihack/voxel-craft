# 学习区建在主世界，不新增维度

学习区作为第 8 种结构「学堂」在主世界程序化生成，而不是新增第 9、10 个维度。

`DIM_N = 8` 与 `PORTAL_BLOCK` / `CORE_ITEM` / `dimSpawn` / `DIMS` 多张表一一绑定，
为学习再扩维度要连带写新的地形生成器、门方块、核心物品与配色，代价远超收益；
而 `collectStruct` + 形状缓存已是现成通道，加一种结构只需一个 `collect*` 函数。

## Consequences

- 学习区与村庄/遗迹/神殿竞争同一套网格锚点，`structAt` 的 hash 概率区间必须重新分配，
  否则学堂会把村庄挤没。
- 学堂的坐标只能在地形生成时收集（结构形状是纯函数、按坐标查询），
  不能事后枚举——交互入口要挂在结构生成这一侧。
