# 语音走 speechSynthesis，且必须能静默降级

英语朗读走浏览器原生 `speechSynthesis`，封装在 `speak()` 接口后面，不可用时静默降级为纯文字。

真人音频音质更好，但要引入音频文件、放大打包体积，且自制素材同样绕不开版权；
原生方案零依赖、离线可用。代价是音色依赖用户系统、iOS Safari 必须由用户手势触发。

## Consequences

- 所有调用点必须把 `speak()` 当作**可能什么都不做**的函数来写，
  绝不允许出现「朗读完再判定」这类依赖语音时序的逻辑。
- `speak()` 是唯一的语音出入口：将来换真人音频只改实现，调用点不动。
