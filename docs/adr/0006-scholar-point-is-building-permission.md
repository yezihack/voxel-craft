# 学识只兑换建造权限，不兑换资源，也不是分数

完成课业获得的学识（Scholar Point）只用于兑换**建造权限**：特殊建材、维度核心、
学堂扩建图纸。它不兑换方块，不兑换生存物资，也不是成绩展示。

创造模式本来就无限方块，发方块当奖励毫无意义；生存模式下若允许学识换物资，
学习会立刻降级成「刷课业攒材料」的打工。把学识绑在「能造什么」上，
才让「学」与「造」形成闭环——学到的东西直接变成世界里看得见的建筑。

## Considered Options

- **发资源 / 发方块**：创造模式下零价值，生存模式下变成打工。
- **做分数 / 等级展示**：与沙盒没有任何耦合，玩家没有理由为了分数继续玩。
- **解锁建造权限**（选定）：奖励本身就是沙盒的核心乐趣——更大的建造自由度。

## Consequences

- 生存模式**暂不支持**学识兑物资。若将来开放，需要单独评估（会退化成打工的风险仍在）。
- 解锁表必须是 `learning/unlock.js` 里的一张纯数据表，不许散在组件里，
  否则「多少学识能换什么」会失去唯一真相。
- 反过来说：任何「给玩家发东西」的设计都要先问一句——创造模式下它还有价值吗？
