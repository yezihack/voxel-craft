# 小学 3–4 年级语文/英语的词条范围到底有多大？

在写任何代码之前，先把「教什么」钉死。需要一份可核对的清单：

- 语文：3 年级 / 4 年级识字表各多少字（去重后合计）、必背古诗篇目、  
  词语与句式类型各覆盖哪些。
- 英语：3 年级 / 4 年级话题词汇量与词表边界、自然拼读覆盖到哪一级  
  （字母音 → CVC → 长元音？）、核心句型清单。
- 每个学科各题型的**判定方式**（什么算对：同义算不算？大小写？标点？）。

产出物是一份数字：语文 N 条词条、英语 M 条词条，以及题型清单。  
这个数字直接决定课程数据文件的体量与是否需要按需加载。

⚠ 边界见 ADR-0004：只收事实性素材，不收课文原文。

## Answer

2026-10-16 定稿（实测数字来自 `npm run check:curriculum`）：

**语文 310 条**
| kind | 数量 | 说明 |
|---|---|---|
| 生字 | 128 | G3 64 / G4 64，**基础集**，按主题分组 |
| 词语 | 96 | G3 48 / G4 48，拼音 → 词语 |
| 古诗 | 12 | 全部公有领域，按句切分（连诗句用） |
| 多音字 | 20 | 每字两个读音 + 例词 |
| 量词 | 24 | 名词 → 量词 |
| 近反义 | 30 | 词 + 近义 + 反义 |

**英语 303 条**
| kind | 数量 | 说明 |
|---|---|---|
| 词汇 | 237 | 14 个话题（数字/颜色/动物/食物/家庭/学校/身体/天气/服装/运动/职业/地点/时间/动作） |
| 句型 | 16 | 缺词填空，G3 8 / G4 8 |
| 自然拼读 | 50 | 10 个 CVC 词族 × 5 词，**每词自带中文释义** |

**合计 613 条词条。**

题型收敛为三类（原设想的 MATCH 砍掉，连诗句用 ORDER 已够）：
`PICK`（选）/ `SPELL`（拼）/ `ORDER`（排）。判定一律走选项 id 或规范化字母序列，
不做原始字符串比较。

**两个已知缺口**（不影响开工，但要知道）：
1. 生字 128 距教材识字表全量（3–4 年级合计约 500）还有距离，是**刻意先做基础集** ——
   收录标准是「高频且能组成常用词」，缺的往数组里追加即可，不影响任何逻辑。
2. 词汇 237 略少于预期的 300+，补词同样是纯追加操作。

**踩到的一个坑**：同一个词会跨话题出现（teacher 在「学校」和「职业」、
orange 在「颜色」和「食物」）。按「话题 × 词」各建一条会导致 id 撞车，
而 id 是要存进掌握度的。现已改为**一词一条、多话题挂在 topics 里**。
