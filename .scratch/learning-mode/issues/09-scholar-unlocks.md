# 学识 → 建造权解锁

这是整个系统的驱动力。⚠ 创造模式本来就无限方块，**奖励发方块毫无意义**。

兑换关系设计为「学 → 造」：学识解锁的是**建造权限**，不是资源。
✅ 已确认（2026-10-16），见 ADR-0006：学识只兑建造权限，不兑资源、不做分数展示。

- 解锁项：特殊建材（发光字块、诗碑方块）、维度核心（`CORE_ITEM`，即去往新维度的钥匙）、
  学堂扩建图纸。
- `unlock.js` 里是一张纯数据的解锁表（阈值 → 解锁什么），不要散在组件里。
- 生存模式下学识是否可以兑换资源？**先不做** —— 会把学习降级成打工。

验收：一个只学习不挖矿的玩家，能凭学识拿到第一枚维度核心并真正打开一扇传送门。
