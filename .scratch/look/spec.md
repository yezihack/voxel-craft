# 手机视角太灵敏 / 僵尸白天不烧

## 一、触屏视角「一低头就跳到最抬头」

### 现象
竖屏手机上想低头看脚下挖方块，手指稍微一动视角就冲到边界，来回弹，瞄不准。

### 根因（两条叠加）
1. **灵敏度太高**：`TOUCH_LOOK = 2.2`，配上 `SENS = 0.0022`，
   每像素转 0.277°。**滑 100px 转 27.7°，滑 324px 就转满 90°**，
   从屏幕顶滑到底能转 234°。手指稍微一动就撞边界。
2. **delta 可能爆炸**：`touchstart` 里 `if (lookId !== null) return`，
   而 `endLook` 只按 identifier 匹配复位。touchend 一旦被系统手势 /
   遮罩 / 元素移除吞掉，`lookId` 就永久挂着 → 之后每次 touchstart 都被挡掉 →
   `lookX/lookY` 停在很久以前的位置 → 下一次 touchmove 的 delta 是几百像素，
   视角瞬间被甩到边界。这才是「一低头变成最抬头」的真正来源。

### 做法（input.js）
- `TOUCH_LOOK` 2.2 → **1.15**（滑 100px 转 14.5°，滑满一屏约 116°）。
- 新增 `TOUCH_STEP_MAX = 90`：单次 touchmove 最多算 90px，
  浏览器合并事件或基准过期时不会一次甩出几百像素。
- `endLook` 加兜底：identifier 对不上但 `e.touches.length === 0` 时无条件复位
  （和 TouchControls 里摇杆那套一致）。
- `touchstart` 里 `lookId !== null` 时先确认那根手指还在 `e.touches` 里，
  不在就接管。
- `PITCH_LIM` 从 `π/2 - 0.02`（差 1.15° 就顶住）放到 `π/2 - 0.0005`（差 0.03°）。
  只保留这一点点余量是为了防 sin/cos 在正好 ±π/2 时视图矩阵退化（画面翻转）。
  **不能真的删掉** —— 删了 pitch 会越过 ±90°，画面上下颠倒，更没法挖。

### 验证（.scratch/look/probe.mjs，CDP 真触摸）
| 项 | 改前 | 改后 |
|---|---|---|
| 滑 100px 转多少度 | 27.7° | **14.5°** |
| 下滑 200px | -55.5° | **-29°** |
| 一路滑到底 | -88.9° | **-90°**（真正垂直向下） |
| 双指不抢视角 | 通过 | 通过 |
| 基准过期不跳变 | 通过 | 通过 |

截图 `look-down.png`：pitch = -89.9°，准星带挖掘框正对脚下方块。

## 二、僵尸白天不燃烧

### 根因
**根本没实现**。`mobs.js` 里只有岩浆灼烧（`BLOCKS[feet].hot`），
没有任何日光伤害逻辑。

### 做法（mobs.js / post.js）
- `SUNBURN_TYPES = { zombie: 1, skeleton: 1 }`，`SUNBURN_DPS = 2.2`
  （20 血的僵尸约 9 秒烧死，比一刀一刀砍慢，但够逼它退场）。
- `underOpenSky(x, y, z)`：从头顶一路扫到世界顶（H=64），
  碰到实心方块就算被遮住。躲在树荫 / 洞里 / 水下的怪不会烧。
- `sunburnTick(m, dt)`：每 **0.4 秒**才重算一次头顶（`m.skyT`）——
  64 只满编也只有 160 次/秒的竖直扫描，比每帧扫一遍便宜两个数量级。
- 挂在 `updateMobs` 的 `mobPhysics` 之后、`dead` 检查之前，
  这样「烧死」和「岩浆烧死」走同一条收尸路径（掉落照给）。
- `spawnMob` 里显式铺 `burning / burnFx / burnPt / skyT` 字段，
  别让 `|| 0` 现场补导致对象形状中途变化。
- 渲染（post.js）：三态 tint —— 正常 / 被打中（纯红）/ 燃烧（橙红 + 跳动）。
  **燃烧时不能走受伤那条**：`sunburnTick` 会把 `hurtFlash` 抬到 0.12 当底噪，
  若按 `hurtFlash > 0` 叠加受伤红，绿色通道被压到 0，整只僵尸变成一块血红，
  看着像被打而不是在烧。改成 `hurtFlash > 0.2` 才算「被打中」，
  燃烧单独走橙色（绿通道留 0.5~0.85 随火苗抖 —— 有绿才是火，没绿是血）。
- 火苗粒子：每 0.3 秒从身体中段喷一小簇橙色粒子。

### 验证（.scratch/sunburn/probe.mjs，18 条断言）
- 白天露天 5 秒掉 11.2 血（期望 11.0）✓
- 白天有整片天花板遮挡 → 一滴不掉，`burning=false` ✓
- 夜里露天 → 不掉血 ✓
- 骷髅白天也烧 ✓；猪、苦力怕不烧 ✓
- 残血烧光 → `dead=true` 且从 `mobs` 里清掉 ✓
- 盖顶后 `burnFx` 1.00 → 0.00 渐熄 ✓
- 夜里拨到白天，同一只僵尸开始掉血 ✓

截图 `zombie-burning.png`：正午、露天，僵尸通体橙红 + 脚下橙色火星。

## 踩坑
- **dev server 的 HMR 会让 `import('/src/game/xxx.js')` 拿到另一个模块实例**。
  改完文件后跑测试，读到的是新实例的 `player`（pitch 恒 0）或新实例的 `mobs`
  （僵尸不烧），一度以为改坏了。**改完代码要重启 dev server 再测**。
- 无头测试里僵尸会追玩家（实测 1.3 秒走 5 格），
  截图时得开 `player.fly` 悬停 + `setInterval` 把僵尸钉在原地，
  否则它贴到镜头前，画面里全是它。
- 遮挡测试的天花板必须盖一整片：只盖一格的话僵尸走两步就晒到了。
