没有引擎，也跑得起来

市面上的 3D 网页游戏大多站在 Three.js、Babylon 或一整套引擎肩上。voxel-craft 不。它从底层开始自己写：顶点缓冲、VAO、uniform 布局、区块网格、面剔除、顶点 AO，再到泛光与 FXAA 后处理链，全是手写。Vue 3 只负责 UI 层，运行时依赖只有 vue。

贴图也程序化生成——一张 512×512 图集打包全部材质，运行时零图片请求，断网也能玩。

手机也能玩

桌面 · 键盘鼠标

  • WASD 移动
  • 鼠标左/右 挖掘 / 放置·进食·格挡
  • E 背包 / 合成台
  • F5 / F9 保存 / 读取
  • 空格 / Shift 跳跃 / 疾跑·飞行

触屏 · 手机

  • 左摇杆 移动
  • 滑动 任意位置转视角
  • 右二键 挖掘 / 放置（按住生效）
  • 右上 背包 / 模式 / 飞行 / 菜单
  • 设计 挖放用专用按钮，不复用画布手势

电容屏分不清「手指停顿」和「长按」，所以挖掘与放置做成两个独立按钮——否则想转个视角就会在脚下挖出一个坑。

存档与工程

本地存档

F5 保存 / F9 读取，每 60 秒自动存一次。地形是 纯函数，所以地形本身零字节入档——只存「世界参数 + 8 维度改动覆盖层 + 玩家状态」，只有你真正动过的方块才占空间。

能无头测试

src/game/ 完全不依赖 Vue 组件，可在 Node 里直接 import 跑断言。每个功能一个 .scratch/ 工单加 probe.mjs 冒烟测试，不需要浏览器也能验证内核。
