# 方块世界 · voxel-craft

> 纯手写 WebGL 的 3D 体素沙盒 —— 没有 Three.js，没有 Babylon，没有游戏引擎。
> 从顶点缓冲、着色器、区块网格到光影后处理，全部自己写。

一个可玩的 Minecraft 风格沙盒：8 个维度、84 种方块、87 种物品、16 种生物 + 3 只 Boss、
会自己盖房子的 AI 玩家、本地存档，键盘与触屏双端可玩。

- **技术栈**：Vue 3（只负责 UI 层）+ Vite + 原生 WebGL 2 / WebGL 1 自动降级
- **零运行时依赖**：`vue` 是唯一的 production dependency
- **离线可玩**：贴图全部程序化生成，无任何图片资源文件
- **体积**：生产构建 gzip 后约 126 kB（JS 120 kB + CSS 4.5 kB）

---

## 快速开始

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 产物在 dist/
npm run preview  # 预览生产构建
```

浏览器需要支持 WebGL。打开页面后点「开始游戏」，桌面端会锁定鼠标，`Esc` 随时退出。

## 玩法

### 三种模式

| 模式 | 说明 |
|------|------|
| 创造 | 无限方块库，飞行，瞬破 |
| 生存 | 生命 / 饥饿 / 氧气，挖掘耗时，合成台，护甲减伤 |
| 旁观 | 穿墙观察，不参与世界交互 |

### 八个维度

主世界 🌿 · 熔火深渊 🔥 · 虚空群岛 🪂 · 霜寂永夜 ❄️ · 晶簇洞天 💎 · 腐化沼泽 🍄 · 炙沙之境 🏜 · 天空花园 🌸

每个维度是一整套参数（地形形态、方块配色、天空、雾、环境光、重力、刷怪池、致死高度），
换维度 = 换一组参数 + 换一张改动表 + 重建区块，不搬动任何体素数据。

用**维度核心**对黑曜石门框右键即可点燃传送门。

### 生物与 Boss

16 种常规生物（猪、羊、鸡、僵尸、苦力怕、骷髅、蜘蛛、史莱姆、铁/石/雪傀儡、村民……），
外加三只只能由玩家主动召唤的 Boss：

| Boss | 召唤方式 | 行为 |
|------|----------|------|
| 末影龙 | 末影龙刷怪蛋（8 黑曜石 + 钻石） | 飞行盘旋，远程喷弹 |
| 凋灵 | 凋灵刷怪蛋（8 黑曜石 + 火药） | 飞行，球形爆破（只炸方块不自杀），贴身轰击 |
| 远古守卫 | 远古守卫蛋（8 黑曜石 + 金矿） | 地面追击，召唤小史莱姆援军 |

Boss 固定掉落稀有材料（龙鳞 / 凋灵骨 / 守卫核心），用来合成唯一的 **tier 5 星陨装备**。

### 装备

- **武器**：木 / 石 / 铁 / 金 / 钻石 / **星陨** 六档，星陨剑 9 点伤害（钻石剑 7）
- **盔甲**：4 部位 × 4 材质 = 16 件，减伤 `min(0.72, 点数 × 0.032)`，星陨整套 72% 封顶
- **盾牌**：木盾 50% / 铁盾 68%，按住右键格挡，与护甲**相乘**叠加，保留 1 点伤害下限
- 护甲只挡打击，摔落 / 缺氧 / 岩浆 / 仙人掌 / 饥饿一律穿透 —— 否则「吃东西」这个循环就没意义了

### AI 玩家

同屏最多 25 个 AI 玩家。它们不是站着发呆的布景，会自己：

- **采集**：找矿脉、砍树，只收进建材白名单（不会捡一堆泥土）
- **合成**：原木 → 木板 → 木棍 → 工具，一路升到铁级，还会搓火把
- **盖房**：4×4 蓝图，33 格围墙（3 高通高门洞）+ 11 格平顶，建材不够就回去补货再断点续盖
- **战斗**：看见敌对生物会上去打，血少了回家上药
- 被打死会掉出背包里的东西，空手也有保底战利品

### 存档

`F5` 保存 / `F9` 读取，每 60 秒自动存一次（触屏走暂停面板的「保存进度」）。

地形是**纯函数**，所以地形本身零字节入档 —— 只存「世界参数 + 8 维度改动覆盖层 + 玩家状态」。
原始地形不占空间，只有你真正动过的方块才占。

| `F` | 飞行开关 |

### 触屏

| 操作 | 方式 |
|------|------|
| 移动 | 左下摇杆 |
| 转视角 | **任意位置滑动画面** |
| 挖掘 / 放置 | 右下两个独立大按钮（按住生效，放置支持连发） |
| 跳跃 / 潜行 | 右下上排 |
| 背包 / 模式 / 飞行 / 菜单 | 右上四个按钮 |

设计取舍：电容屏分不清「手指停顿」和「长按」，所以挖掘与放置**不再**复用画布手势，
改成两个专用按钮 —— 否则想转个视角就会在脚下挖出一个坑。

## 技术要点

### 渲染

- **手写 WebGL**：顶点 / 片元着色器、VAO、uniform 布局全部手工管理，无引擎抽象层
- **区块化网格 + 面剔除**：`VIEW_CX = 4` 的区块窗口，只为新进入视野的一圈重建几何；
  六面邻居做 `isOpaque` 判定，被完全遮住的面直接不生成
- **顶点 AO**：每个顶点按周围遮挡情况烘焙环境光遮蔽，写进交错缓冲
- **两趟绘制**：不透明趟开深度写入、关混合；半透明趟（水 / 玻璃）开混合、关深度写入
- **后处理链**：离屏帧缓冲 → 亮部提取 → 两次可分离高斯 → 合成。
  换来泛光（岩浆/萤石真的在发光）、调色（软压缩高光 + 暗角 + 轻微加饱和）、
  FXAA（离屏会丢 MSAA，FXAA 不是装饰是必需品）
- **程序化贴图**：`textures.js` 用噪声函数在 canvas 上画出全部贴图，
  打包进一张 512×512 图集（217 / 256 格），运行时零图片请求

### 世界生成

- 地形是 `(seed, x, z)` 的**纯函数**，`fbm` + `hash2` 噪声，无状态、可随时重算
- 只把玩家改动记在 `edits` 覆盖层（按维度分表），读取时覆盖层优先
- 结构（村庄 / 遗迹 / 沙漠神殿 / 冰屋 / 废弃矿井 / 丛林神庙）走「结构格」网格，
  每 96 格一个候选位置，用哈希决定生成什么

### 工程约束

几个踩过的坑，写在 `GLOSSARY.md` 和 `.workbuddy-ai/memory/MEMORY.md` 里：

- `armor.js` 只能依赖 `config.js`。若反过来引 `survival.js`，
  `survival → armor → survival` 成环，`hurt()` 拿不到减伤值
- 减伤入口只有 `survival.hurt(n, reason, opts)`：环境伤害必须传 `{pierce:true}`，
  外部打击不传 → 走护甲 + 盾牌减免
- `isOpaque(id)` 必须排除带 `shape` 的薄片方块（火把 / 铁轨），
  否则相邻实心块朝向它的面会被剔掉，薄片背后空一片 → 透视穿帮
- Boss 的 AI 分支必须放在 `if (D.hostile)` **之前**，否则会混进普通敌对的路径

## 项目结构

```
src/
├── game/                 游戏内核（不碰 Vue，纯 JS 模块）
│   ├── config.js         常量：世界尺寸 / 84 方块 / 87 物品 / 顶点布局
│   ├── generate.js       地形纯函数 + edits 覆盖层 + isOpaque
│   ├── world.js          列高度 / 生物群系
│   ├── dims.js           8 个维度的参数档案
│   ├── fluid.js          水 / 岩浆流动 + 矿脉 + 结构生成
│   ├── mesher.js         区块网格构建、面剔除、顶点 AO
│   ├── renderer.js       WebGL 上下文与着色器
│   ├── post.js           后处理（泛光 / 调色 / FXAA）与几何绘制
│   ├── sky.js            天空盒与昼夜插值
│   ├── textures.js       程序化贴图生成器
│   ├── player.js         玩家物理与射线
│   ├── survival.js       生命 / 饥饿 / 氧气 / 背包 / hurt 入口
│   ├── armor.js          护甲槽位与减伤计算
│   ├── mobs.js           16 生物 + 3 Boss 的 AI / 物理 / 掉落
│   ├── bots.js           AI 玩家：采集 / 合成 / 盖房 / 战斗
│   ├── crafting.js       99 条配方 + 配方匹配
│   ├── spell.js          拼写合成（字块 → 课程词表）
│   ├── carts.js          矿车与铁轨
│   ├── transport.js      传送带 / 传送板
│   ├── portal.js         维度传送门
│   ├── save.js           localStorage 存档 / 读档
│   └── ...
├── components/           Vue UI 层（HUD / 面板 / 触屏控件）
├── data/                 模式、世界类型、课程词表
└── engine.js             对外门面：UI 只通过它调用内核
```

`src/game/` 完全不依赖 Vue 组件；UI 通过 `engine.js` 这个门面读写游戏状态。
这条边界让内核能在 Node 里无头跑测试（见下）。

## 验证

```bash
npx vite build                 # 生产构建，约 99 modules
node .scratch/<topic>/probe.mjs  # 无头冒烟测试
```

`.scratch/` 下每个功能一个目录，装 `spec.md`（工单：根因 / 做法 / 验证）与
`probe.mjs`（Node 里直接 import 内核模块跑断言，不需要浏览器）。

已归档的工单：

| 目录 | 内容 |
|------|------|
| `.scratch/transport/` | 超平坦 / 矿车 / 红石 / 传送装置 |
| `.scratch/boss/` | 火把铁轨透视修复 + 三种 Boss |
| `.scratch/bots/` | AI 玩家合成 / 盖房 / 掉落 |
| `.scratch/gear/` | 星陨武器 / 盔甲 / 盾牌 / 存档 |
| `.scratch/mobile/` | HUD 移除 + 触屏重做 |

移动端布局用 Playwright 起真触屏上下文实测（`.scratch/mobile/shot.mjs`），
量元素矩形判断控件是否互相压住 —— 光看构建通过发现不了这类问题。

## 部署

产物是纯静态文件，任意静态托管都能放。

### Cloudflare Pages

```bash
npm run build
npx wrangler pages deploy dist --project-name voxel-craft
```

首次需要 `npx wrangler login`。也可以在 Cloudflare Dashboard 里连 GitHub 仓库，
构建设置填：Build command `npm run build`，Output directory `dist`。

### 本地预览

```bash
npm run preview
```
